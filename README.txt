VOYAGO — демонстрационный туристический сайт

Страницы:
- index.html  — главная страница и направления
- stays.html  — отдельная страница жилья
- flights.html — отдельная страница авиабилетов
- cars.html   — отдельная страница аренды автомобиля
- taxi.html   — отдельная страница такси и трансфера

Структура:
- CSS/style.css — стили всех страниц
- js/main.js — интерактивность
- images/ — сюда можно положить собственные фотографии

Запуск:
1. Распакуйте архив.
2. Откройте index.html в браузере.
3. Используйте меню, чтобы переходить между отдельными страницами.

Собственные фото:
В папку images можно положить italy.jpg, france.jpg, japan.jpg,
switzerland.jpg и greece.jpg. Они будут использоваться на карточках
направлений, если файлы существуют.

Важно:
Это front-end демонстрация. Формы поиска показывают тестовое сообщение.
Для реального бронирования, оплаты, аккаунтов и рассылки необходимы сервер
и подключение API соответствующих поставщиков.
